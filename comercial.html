Activar el botón Actualizar (solo una vez)

Para que el botón pueda iniciar la actualización en GitHub necesita una clave de tu cuenta. Se guarda solo en este teléfono o computadora; no queda en la página publicada.

  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → Cmg-Rosa.
  3. Permissions → Repository → Actions: Read and write. Expiración: 1 año.
  4. Copia la clave (empieza con github_pat_) y pégala aquí.
